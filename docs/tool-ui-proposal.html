The 4-layer contract

LayerUser intentShowHide
L0 Glance“did it work?”Outcome sentence in human words, 1 status dot, total timeTool names, counts, IDs, ms, files
L1 Explore“what catches my eye?”3–5 curiosity nodes phrased as questions/topics, anomalies firstChronology — order by interest, not time
L2 Investigate“show me that one”Only the opened node: diff, result, or reviewer log + actions (retry/accept)Everything else stays shut
L3 Audit“prove it”Full raw log — current view, behind Ctrl+ONever in default scrollback

Explorer affordances

• Hooks, not summaries: L0 deliberately leaves one open loop (“review incomplete”) — explorers pull threads, monitors read reports.
• Keyboard: Tab jumps between L1 nodes · Enter opens · Ctrl+O raw · Esc collapses to L0.
• Follow-thread: opening a node offers its next thread only (fixes → diff → that file), never siblings.
• While running: L0 line rewrites in place: ⠹ Reviewing — 2 of 3 back… No rows accumulate.
• Memory: collapsed turns persist as L0 lines only, so scrollback reads as a story of outcomes, searchable by result.

Implementation (unchanged cost)
